# Testing & Final Review

## Automated Tests
- Tests are located in the `test/` directory.
- Run tests with: `npm test`
- Sample tests provided for user and news services.

## Manual Testing
- Register, login, and admin features should be tested in the browser.
- Verify permissions and error handling for all roles.

## Code Review Checklist
- Security: Passwords hashed, sessions secured, secrets in .env
- Maintainability: Modular code, comments, clear structure
- Accessibility: Semantic HTML, ARIA roles, keyboard navigation
- Documentation: All features and setup steps documented

## How to Contribute
- Fork the repo, create a feature branch, submit a pull request
