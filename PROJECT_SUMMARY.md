# Travlr Getaways Full Stack Project Summary

## Overview
Travlr Getaways is a full stack web application for a travel business, featuring:
- Static and dynamic pages
- News management
- User authentication
- Admin dashboard
- Cloud deployment
- Automated testing

## Technologies
- Node.js, Express, Handlebars
- SQLite
- JavaScript, HTML, CSS
- Mocha (testing)

## Features by Module
- **Module 1:** Static site, accessibility, semantic HTML
- **Module 2:** Express backend, REST API, SQLite integration
- **Module 3:** Authentication, registration, login, session management
- **Module 4:** Admin roles, permissions, dashboard, user/news management
- **Module 5:** Deployment setup, environment variables, cloud readiness
- **Module 6:** Automated tests, documentation, code review
- **Module 7:** Final submission, project summary, presentation

## How to Run
1. Install dependencies: `npm install`
2. Set up `.env` file
3. Start server: `npm start`
4. Run tests: `npm test`
